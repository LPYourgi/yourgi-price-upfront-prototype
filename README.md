# Yourgi — Book Now live price estimate (prototype)

Clickable prototype for the "Move price early in booking process" ticket.
Open `index.html` (or the GitHub Pages link) and use the toggles:

- **Form factor:** Mobile web / Web
- **State:** Today (no price) / Proposed (fee-inclusive estimate)

Tap calendar days to watch the estimate build (rate × days × 1.05).
Matches the Figma "Booking-estimate-flow" widgets field-for-field. Rates are mock.
